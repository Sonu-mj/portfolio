03 · Projects

Work that runs somewhere.

Five projects, one shape: the problem, what I built, and what it does now.

RetailIQ - Multi-Outlet Retail Analytics Platform

Problem: small retail outlets had billing software but no idea what their own sales data was saying.

Built the full platform and its ML layer: an Isolation Forest anomaly detector (240 estimators, contamination 0.08) that flags unusual sales patterns with explainable severity scoring, and a HistGradientBoostingRegressor demand forecaster evaluated on MAE, RMSE and MAPE, feeding automated staff planning. Live on Vercel with a Supabase backend, role-based access and audit logging.

Live demo · Repo

Python · scikit-learn · Pandas · Supabase · PostgreSQL

RAG from Scratch

Problem: every RAG tutorial hides the retrieval inside a library call. I wanted to know what actually happens.

Wrote the whole pipeline by hand in Python: a sentence-aware chunker (500 chars, 75 overlap), TF-IDF embeddings, and a NumPy cosine-similarity vector store. Ships with a CLI and a self-test. Retrieved chunks ground every answer in source documents - no framework magic.

Repo

Python · NumPy · NLP · Information Retrieval

AirBrush - Draw in the Air, Create with AI

Problem: drawing apps need a mouse or a tablet. Your hand is already a pointer.

A browser app that turns a webcam into a drawing tool: MediaPipe Hands tracks 21 hand landmarks (index finger draws, two fingers erase, palm pauses). Sketches go through sketch-guided AI image generation, with 10 art styles, voice input and an in-browser gallery.

Live demo · Repo

JavaScript · MediaPipe · GenAI APIs

Distributed Consensus Lab

Problem: distributed systems courses describe Raft. I wanted to watch it elect a leader.

A from-scratch Raft implementation in TypeScript: leader election, log replication, commit protocol, stale-term handling, manual fail and recover. Backed by 94 engine tests and a live visualization of node states, the event timeline and the replicated log.

TypeScript · Algorithms · Distributed Systems

Library Management System

Problem: a class project that could have used a list. I used it to learn how databases index.

A Python library app with a custom-built AVL tree storage engine: books and students indexed in self-balancing trees giving O(log n) search, insert and delete, with rotations handled by hand. CLI and web UI on top.

Repo

Python · Data Structures · Algorithms
